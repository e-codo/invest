# Стройка фундамента

Личный трекер долгосрочного портфеля: взносы, покупки, купоны и дивиденды, вехи, аллокация и график роста.
Один пользователь, вход по паролю. Рубли, Мосбиржа.

Стек: Next.js (App Router), TypeScript, Tailwind CSS, Postgres на Vercel.

## Запуск локально

```bash
npm install
cp .env.example .env.local   # задайте APP_PASSWORD и SESSION_SECRET
npm run dev
```

Открыть http://localhost:3000. Без действующей сессии все страницы ведут на `/login`.

Сгенерировать `SESSION_SECRET`: `openssl rand -base64 48`.

## Как устроен вход

- Пароль задаётся переменной `APP_PASSWORD`, в коде и в git его нет.
- После входа выдаётся подписанная кука `session` (HttpOnly, SameSite=Lax, Secure в production) на 30 дней.
- Сессию проверяют `src/proxy.ts` (первая линия) и каждая страница через `requireSession()`.
- Чтобы разлогинить все устройства сразу, смените `SESSION_SECRET`.
