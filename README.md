# Стройка фундамента

Личный трекер долгосрочного портфеля: взносы, покупки, купоны и дивиденды, вехи, аллокация и график роста.
Один пользователь, вход по паролю. Рубли, Мосбиржа.

Стек: Next.js (App Router), TypeScript, Tailwind CSS, Postgres, Drizzle ORM.

## Запуск локально

Нужен Postgres. Быстрый вариант: создать базу `invest` с пользователем `invest` (пароль `invest`) или взять любую свою.

```bash
npm install
cp .env.example .env.local   # задайте APP_PASSWORD, SESSION_SECRET и DATABASE_URL
npm run db:migrate           # создаёт таблицы
npm run dev
```

Открыть http://localhost:3000. Без действующей сессии все страницы ведут на `/login`.
После входа, пока портфель не настроен, вы попадаете в мастер первого запуска (`/setup`).

Сгенерировать `SESSION_SECRET`: `openssl rand -base64 48`.

## Как устроено

**Вход.** Пароль задаётся переменной `APP_PASSWORD`, в коде и в git его нет. После входа выдаётся подписанная кука `session` (HttpOnly, SameSite=Lax, Secure в production) на 30 дней. Сессию проверяют `src/proxy.ts` (первая линия) и каждая страница и действие через `requireSession()`. Чтобы разлогинить все устройства сразу, смените `SESSION_SECRET`.

**База** (`src/db/schema.ts`):

- `portfolio`: одна строка с настройками. Стратегия (доли акций, облигаций и ликвидности, всегда в сумме 100), цель, ожидаемая доходность и ежемесячный взнос для прогноза, заголовок, подзаголовок и цитата.
- `milestones`: вехи.
- `instruments`: фонды и бумаги с классом актива.
- `transactions`: взнос (`deposit`), покупка (`buy`), доход (`income`). Реинвест купона это две записи в один день.
- `prices`: цены бумаг на первое число месяца, вводятся при ежемесячной отметке.

Деньги хранятся как `numeric`, а в коде это строки и целые копейки (`BigInt`), без чисел с плавающей точкой (`src/lib/money.ts`).

**Мастер первого запуска** (`/setup`): стратегия (три готовых и своя), цель и вехи, фонды, необязательное начальное состояние, проверка. Сохраняется одной транзакцией, повторно пройти его нельзя. Начальное состояние превращается в стартовый взнос и покупки на выбранную дату.

**Форма «месяц»** (`/month`): за выбранный месяц вносятся взнос, покупки (по несколько на фонд), купоны и дивиденды, актуальные цены. Переключатель «Реинвестировал» создаёт две записи: доход и покупку в тот же день. Цена обязательна для каждой бумаги, которая есть в портфеле: без неё нельзя оценить его стоимость. Повторная отметка того же месяца добавляет операции и обновляет цены. На главной есть список последних операций с удалением (в два нажатия).

**Дашборд** (`/`): стоимость портфеля, вложенное, доходность (XIRR), купоны, прогресс к ближайшей вехе и цели, график роста (факт, прогноз и «только взносы»), календарь взносов на три года, аллокация против стратегии, последние операции. Заголовок, подзаголовок и цитата правятся прямо на странице. Расчёты лежат в `src/lib/portfolio.ts` и `src/lib/dashboard.ts` без обращений к базе, покрыты тестами.

- Стоимость портфеля = штуки × последняя известная цена + свободные деньги на счёте (взносы и доход минус покупки). Свободные деньги в аллокации считаются ликвидностью.
- Доходность (XIRR) считается по взносам и текущей стоимости, показывается от 3 месяцев истории.
- Прогноз: ставка и ежемесячный взнос задаются в `/settings`. Если взнос не задан, берётся среднее за последние 6 месяцев со взносами. Это сценарий, а не обещание.

**Настройки** (`/settings`): стратегия, цель, вехи, ставка и взнос прогноза.
